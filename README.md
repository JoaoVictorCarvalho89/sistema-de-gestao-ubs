# sistema-de-gestao-ubs
O seguinte repositório visa armazenar a documentação e código um trabalho escolar promovido pela professora Tatiana. Tal aplicação web trata-se de um sistema gerenciador de unidades básicas de saúde (UBS), servindo como protótipo para atender à uma demanda real de modernização do serviço público na área da saúde.
